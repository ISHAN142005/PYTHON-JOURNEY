## 1. Comments in Python
Comments are written notes used to explain code logic. They make code readable for humans and are completely ignored by the Python interpreter during execution.

*   **Single-line comments:** Start with the hash symbol (`#`).
*   **Multi-line comments:** Enclosed within triple single quotes (`'''`) or triple double quotes (`"""`).

```python
# This is a single-line comment

'''
This is a
multi-line comment
'''
